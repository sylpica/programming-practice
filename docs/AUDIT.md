# 実装・監査記録（2026-11-14 JST）

## 実装判断

- 指定どおりビルド不要、外部ライブラリ不要の本体。パーサ・評価・UI・教材・取込を別モジュールに分離。
- 実Excelの値を仮定しない。編集可能なA1:C5をモデルとし、「?」のセルとInputBoxを未確定として保持。
- ASTから分岐を探索。未確定条件は制約を保存し、既知の矛盾・整数として存在しない区間・Caseの重複を除外。
- 未確定ループを無限に展開せず、0～2回とそれ以上の継続を区別。継続側は後続文を実行せず、終了状態と混同しない。
- 非線形・複数未知値の比較、未知Step、String型と数値型の直接比較などは明示的に未対応として停止。完全なVBA処理系の代替とはしない。
- 解析はWorkerへ分離し、探索回数・解析時間に加えてUI側の強制終了も設定。
- Desktopではリファレンス・使用項目をエディタ右側、状態は下側。狭幅ではコードから縦に並べる。
- 8テンプレート、66リファレンス、独立した基本用語集。180×180の実PNGを含むPWA。

## 監査と修正

1. **初期意味論照合**：テンプレートの合計15、Forの最終カウンター6、文字列加工、3つの入力分岐を独立に計算して照合。日本語Sub名の解析誤り、セル変更比較の基準が更新される欠陥を修正。
2. **型・制御フロー**：公式VBA資料と照合。Variant同士の比較と宣言型の比較を分離。Empty / Null、偶数丸め、整数式のオーバーフロー、Select Caseの最初の一致、Step方向、開始時の境界評価、配列下限、On Errorを確認。
3. **分岐監査**：重複Case、矛盾する不等式、And / Orの組み合わせ、整数の開区間、変化しない未確定ループを修正・回帰試験化。線形式のカウンター、正確な等値条件からの値の絞り込み、Len / Absの非負領域を追加。
4. **宣言・エラー行**：Dimは手続きのスコープで初期化し、ループごとに再初期化しない。NextでのオーバーフローとLoopの後判定でのエラーが該当行に結び付くよう修正。後判定の条件を先に評価してしまう欠陥も修正。
5. **耐入力試験**：250件の決定的ファズ、過剰な入れ子、巨大回数・無条件ループ、複雑な未知条件。既定の最大2,000件と小さいカスタム上限を確認。未対応関数に未知引数が渡った場合も正常処理として扱わない。
6. **Chromium実動作**：全テンプレート、手動・自動実行、前後・先頭末尾・数値ジャンプ・Enter、空欄 / 非数値 / 範囲外、ソート時の選択保持、パスごとの使用関数、重複文の行ジャンプ、UTF-8取込・キャンセル・テンプレート解除、永続化を操作。シミュレーション本文をスクロールしても見出しと実行が残ることを確認。
7. **表示・オフライン**：375 / 768 / 1024 / 1440pxで4メニューの横はみ出しなし。200%表示、スクリーンショットの目視、Service Worker制御下のオフライン再読込とWorkerでの再実行を確認。狭幅ではコードを先に配置し、状態のラベルと本文は縦積みに変更。
8. **参照アプリ**：公開ホストへのアクセスは環境のネットワーク制約で不可。両GitHubリポジトリを読み取り、ローカル配信して練習画面を操作した。Python版の自動 / 手動説明、ImageJ版のテンプレート・使用関数・参照本文を確認。Python本体の外部Pyodide読み込みはローカル確認環境では不可だったが、コード説明は操作できた。

各欠陥類型は `tests/engine.test.js` または `tests/browser.py` に回帰試験として収録。最終結果は配信時のActionsおよび実行ログを参照。

## 検証の限界

- Excel / Windows VBAの実行環境はないため、公式仕様・独立計算との照合であり、Excel実機との自動差分試験ではない。
- iOS実機でのインストール試験は未実施。PNGの実在・寸法、manifest、ローカルChromiumのオフライン動作を確認。
- 未確定値の全ての型変換エラーや、関数間のあらゆる関係を解く一般的な定理証明器ではない。対応外の比較は停止するが、複雑な実務マクロ全体の経路を完全に証明する用途は対象外。
- GitHub Pagesは開始時点で `has_pages: false`。接続ツールにPages設定変更機能がなく、設定が有効になるまでは公開処理をスキップする。
