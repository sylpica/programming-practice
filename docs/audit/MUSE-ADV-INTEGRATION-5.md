## 4. 同根スイープの裁定・処置（A6 申し送り）

A6 ラインの引き継ぎ（基礎モジュール概説項目 random／json／datetime の追記が高度モードの実挙動と矛盾する）に対し、統合側で両モードの実挙動を実測して処置した（RG-670）。
