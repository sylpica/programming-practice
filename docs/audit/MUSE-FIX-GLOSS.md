## 項目ごとの処置

### G-N1〜G-N4（RG-136）：C／C++／C# の用語集分離（根本原因への対処）

根本原因は、`js/core/c-family.js` のファクトリが3種類に同一の用語集配列（配列／ポインタ／未定義動作／参照オブジェクト）を返していたこと。用語集を言語ごとに分離した：

- C#（managed）：配列／参照オブジェクト。モデル対象外の「ポインタ」（G-N1、C# 言語仕様 §24：ポインタは unsafe コンテキストのみ）と、教材説明「範囲外の添字は例外として停止します」・semantics「配列範囲検査」と矛盾する「未定義動作」（G-N2）を除外した。
- C：配列／ポインタ／未定義動作。C の教材のどこにも現れない C# 専用語「参照オブジェクト」（G-N3）を除外した。
- C++：配列／ポインタ／未定義動作／参照。「参照オブジェクト」（G-N4）を、C++ リファレンス項目「参照」（`int& ref = n;`「宣言した変数の別名です」）に一致する「参照」へ置き換えた。定義文は「宣言した変数の別名です。参照への代入は、参照先の変数への代入になります。」とし、リファレンス項目の本文と矛盾しない形にした。

波及確認：同じファクトリが構築するリファレンス（C 26／C++ 31／C# 53件）とテンプレート（各種6件）の件数が不変であることを回帰テストで固定した。用語集以外の共有データには触れていない。

### G-N5（RG-137）：Power Automate「デスクトップフロー」定義の是正

旧定義「アクションを条件やループで組み合わせる自動化です。」は、Microsoft Learn「Introduction to desktop flows」が示す定義的特徴（ワークステーション上のデスクトップ処理の自動化）を欠き、クラウドフローと区別がつかなかった。新しい定義：「自分のパソコン（デスクトップ）上のアプリ操作やファイル操作を自動化するフローです。Power Automate for desktop で作成し、アクションを組み合わせて組み立てます。」（本アプリの semantics「Power Automate for desktop の…モデルです」とも一致）。

### G-N6（RG-138）：「未確定（値）」を全15種類の用語集へ追加

全種類共通の定義：「実行時に決まる値のことです。このアプリでは値を仮定して作らず、未確定のまま扱って、到達可能な分岐をすべて表示します。」表示層の表記（`js/core/presentation.js` の「実行時に決まる：…」）とモデル記述（DEVELOPMENT.md の「未確定値」）に一致させた。Python は詳細オブジェクト形式（id: `unknown-value`、related は既存の variable／object を参照）で追加した。

付随是正（独自判断）：R の「NA」定義にあった表記揺れ「実行時の未知値」を「実行時の未確定値」へ統一した（監査報告書の観察事項2が G-N6 処置時の統一を望ましいとしていたもの。事実関係の変更はない）。

## 独自に判断した点

1. C++「参照」の定義文は、リファレンス項目「参照」の主文をそのまま流用せず、要約形（別名＋代入の帰結）にした。用語集の他項目がすべて1〜2文の要約形であることに合わせたためで、意味はリファレンスと一致する。
2. R「NA」定義の表記揺れ（未知値→未確定値）を、監査の観察事項に基づき G-N6 の処置に付随して統一した。欠陥13件の範囲外の変更はこの1点のみ。
3. 「未確定（値）」の項目名は、教材文の表記「未確定」と、値であることを示す「（値）」を併記した監査報告書の表記に合わせ、全種類で統一した。
