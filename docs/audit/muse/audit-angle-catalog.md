# プログラミング練習 監査角度カタログ（第21ラウンドで新規作成）

- 作成：2026-11-15、Muse 側。恒常ルール（ユーザー指示 2026-11-15）「1ラウンドの中で多角的に完結させる」に基づく再利用可能な角度一覧。
- 材料：監査プロンプト（2026-11-14）の角度 A〜F・要件 R01〜R33、findings-round1〜round20 の全系統で実際に使われた角度。
- 使い方：各ラウンドは本カタログの全角度を実施するか、実施しない角度には「対象外」の理由を明記する。収束判定は本カタログ全網羅のラウンドで新規ゼロになった時点で行う（修正済みビルドに対して別途実施）。
- 表記：ID／角度名／対象（種類・表面）／検証方法／初出ラウンド。

## 対象外（本カタログの範囲外として明示）

| 項目 | 理由 |
|---|---|
| 実機（iOS／Android 実機）での確認 | 実機環境がない。代替として D-02（200%ズーム相当幅）・E-02（アイコン実物確認）を実施 |
| スクリーンリーダー実機での読み上げ | 実機・支援技術環境がない。代替として D-04（意味構造）を実施 |
| 印刷レイアウト | アプリに印刷機能の要件がない |
| 実デプロイを伴う種類（CFN の実展開・PAD の実フロー実行等） | アプリの宣言どおりモデル化範囲のみが対象。実在を装う表示は A 群・C 群の正直さ角度で検出する |
