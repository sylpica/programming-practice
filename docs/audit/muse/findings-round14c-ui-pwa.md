## 観察（欠陥として数えなかったもの）

1. **C／JavaScript の初期実行ウォッチドッグ発火（角度1の2件）**：並行監査で VM が競合する状況でのみ発生した。切り分けでは、エンジン直接実行は C 98ms／JavaScript 77ms（VBA 101ms、Python 134ms）、単独環境の UI 実測では種類切替と手動再実行あわせて12回全て成功した（所要 1.0〜4.1秒はページ側の待機を含む）。負荷時の計測アーティファクトと判断し、欠陥には数えない。ただし、実機の低速環境では 2.5 秒のウォッチドッグが重いテンプレートで誤発火しうる点は、観察として残す。
2. **テーマカラーの2系統**：index.html の meta theme-color は `#197655`（UI の緑アクセント `--green` と一致）、manifest の theme_color は `#1b2040`（アイコンの地色と一致）。どちらも実在するデザイントークンに由来し、機能上の不整合ではないため欠陥には数えない。
3. **R12-N33（summary 内のリセットボタン）の実挙動**：キーボードの Enter／Space でパネルの誤開閉は起きなかった。構造の指摘自体は既知残件のままで、本ラウンドでは再計上しない。
