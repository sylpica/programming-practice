## §5 残件・観察（処置対象外として記録）

- **VBA `Len(True)`**：現行は 4（"True" の文字数）を返す。実 VBA の Len は Boolean に対して格納バイト数 2 を返す解釈がありうるが、一次情報で確定していないため未確認候補として分離（VBA・ImageJ班の観察）。
- **Sequence caution の文面**：「最も近い整数へ切り捨てられます」は Microsoft Learn 原文 "rounded down to the nearest whole number" の訳であり、実挙動（純粋な切り捨て。独立検証で 5.7→5・2.5→2 を確認）とも一致するため維持した（独立検証の観察への裁定）。
- **ImageJ の `images` 未指定／null**：デモ画像で受理する設計（班テストで固定済み）であり、R31-N13 の対象外。
- **C# foreach の宣言型と要素型の整合検証**：従来の配列形と同じ緩さに揃えており、新たな検証は追加していない（例：`foreach (string v in int[])` は黙って反復する。C家族班の記録）。
- **擬似言語の括弧なし ×／mod 連鎖への「の商」全体結合**：一次情報がないため未確認候補 U9 の領域として変更なし。
- **JS `console.log(1 .toString)`**：ホスト関数の文字列表現を出力する既存表面は、メンバー参照の意味論側であり本バッチの範囲外として記録のみ（script班）。
- **シェルの cwd／inputs／args 等の型違い**：項目側の既存挙動（文字列化・未確定化）に従うため変更なし。`echo hi |`（パイプ後が空）の無言受理も内部トークン露出ではないため変更なし（シェル班）。
