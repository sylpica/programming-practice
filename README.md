# プログラミング練習

コードとフローの動きを、日本語の説明と明示したモデルで学ぶ静的Webアプリです。HTML / CSS / JavaScriptのみで動き、ビルド・ログイン・外部CDNは不要です。

公開先：https://sylpica.github.io/programming-practice/

## 対象の13種類

| 言語・ツール              | 練習対象とモデル                                                               |
| ------------------------- | ------------------------------------------------------------------------------ |
| Excel VBA                 | セル、変数、配列、エラー。A1:C5のモデルシート                                  |
| ImageJマクロ              | 画像、画素、ROI、測定表。既存ImageJ学習アプリから移植                          |
| AWS CloudFormation Macros | JSON / YAMLのTransform・Fn::TransformとPythonハンドラ。入力／変換後の断片      |
| Power Automate            | Desktopの変数・条件・ループ・ファイル・メール。学習用アクションJSONと編集画面  |
| AutoHotkey v2             | ホットキー／ホットストリング、入力送信、ウィンドウ・マウス。モデル起動イベント |
| UI.Vision RPA             | ClassicマクロJSONのopen / click / type等。モデルURL・要素・入力値              |
| Power Apps                | Power Fxの動作数式と画面構成。コントロール、変数、コレクション、レコード       |
| Python                    | Python学習アプリから移植したコード説明。型、コンテナ、関数、例外               |
| R                         | base Rの数値・論理・文字ベクトル、NA、データフレーム、リサイクル               |
| C                         | 変数、配列、ポインタ、整数演算。シンボルで表すモデルメモリ                     |
| C++                       | C形式の基礎制御・ポインタ・配列、cout。モデルメモリ                            |
| C#                        | int演算、範囲検査、単純クラスと参照共有。モデルオブジェクト                    |
| JavaScript                | 変数・配列・オブジェクトとブラウザAPIの部分集合。モデルDOM                     |

各エンジンは対応する構文の**部分評価器**です。各言語の処理系全体を実装しているわけではありません。対応範囲と未対応項目は、選択した種類の「対応範囲・仕様の出典」と [実装範囲](docs/DEVELOPMENT.md) に明記しています。未定義動作・未確認・対応外の構文では、値を捏造して処理を続けません。

## 起動

```sh
python3 -m http.server 4173
# http://localhost:4173 を開く
```

モジュールとWorkerを使うため、ファイルをダブルクリックする方法ではなくHTTP(S)で開きます。初回オンライン表示後は、全13種類のモジュール・教材をService Workerでキャッシュし、オフラインでも説明できます。iOSホーム画面用の180×180 PNGを含みます。

## 共通操作

- 上部の「言語・ツール」で種類を切り替えます。下書き、テンプレート、モデル、表示モード、ソート、選択パスは種類別に保持します。
- 「実行」と「自動実行」の2モード。未確定の入力・外部値は、モデルから確定できる値と分けます。
- 説明をクリックすると該当行、フローなら対応アクションへ移動します。
- パスの前後、先頭／末尾、番号入力＋移動／Enter、出現順／手順数の降順／昇順を使えます。
- 使用中の項目はエディタ右側に表示します。説明中は表示パスに連動し、チップから書式・説明・使用例・注意へ移動できます。
- 変数・セル・メモリ・モデル状態は下側の「終わったときの状態」に表示します。
- 対応する拡張子のファイルを取り込みボタン／ドラッグ＆ドロップから読み込めます。名前・文字コード・上書き確認とバイナリ除外は共通です。
- Power AutomateとUI.Visionはアクションを追加・編集・並べ替え・削除できます。下側のJSONと同期します。Power AutomateのJSONは本アプリの学習用表現で、製品のエクスポート互換形式ではありません。
- エディタのTabは字下げです。Escを押してからTabでエディタから出られます。

入力は外部へ送信しません。AWSへのデプロイ、実ウィンドウ、実ファイル、メール、実DOMは操作しません。外部リンクは公式資料・ソース参照用です。

## 保存と移行

現在の保存キーは `programming-practice-v3` です。旧 `vba-practice-v1` / `macro-practice-v2` が同じオリジンのlocalStorageにある場合、下書きを移行し、元のキーは削除しません。不正な現在形式の生データは `programming-practice-recovery-v3` へ保全します。保全／保存に失敗した場合は通知し、破損データを保護します。

モデルJSONは編集中に構文が不正でも、生のテキストを種類別に保存します。ブラウザの保存領域が使えない場合は「保存」でファイルへ書き出してください。

## 検証

```sh
npm test
node scripts/precache.mjs --check
# ローカルサーバー起動中、Python PlaywrightとChromiumがある環境で:
python tests/browser.py
python tests/browser-types.py
```

Node標準テストランナーを使うため、本体に `npm install` は不要です。ブラウザ試験のみPython PlaywrightとChromiumを別途必要とします。試験は使い捨てブラウザコンテキストで行います。

本体開発の試験実績は [DEVELOPMENT.md](docs/DEVELOPMENT.md) に記録しています。**Muse／Codexの独立二重監査は、別途届く監査プロンプトに基づく後続フェーズです。本体開発試験の合格を、その監査の収束とは扱いません。**

## 拡張と配信

[種類の追加方法と契約](docs/EXTENDING.md) を参照してください。新しい定義モジュールを追加し、レジストリへ登録します。コアUIの書き換えは不要です。

変更後は次を実行し、生成済みの `precache.js` もコミットします。これは開発時のキャッシュ一覧更新で、本体のビルド要件ではありません。

```sh
node scripts/precache.mjs
npm test
node scripts/precache.mjs --check
```

GitHub Actionsはmainへのpush後にテストとキャッシュ一覧の整合性を確認し、Pagesが有効なら静的ファイルだけをまとめて公開します。公開ルート・manifest・Service Workerは相対パスで、`/programming-practice/` の配下で動作します。
